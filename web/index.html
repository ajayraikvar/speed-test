iAbout this test

Download and upload measure HTTP/TCP throughput between your browser and the host. Multi-stream tests run parallel HTTP connections. Latency and jitter use repeated HTTP round trips, not ICMP ping.

For best comparison, use wired Ethernet on both PCs, stop other heavy transfers, and keep the duration and stream count consistent.
