# Changelog

## 1.0.0-rc.1

- Initial self-hosted Speed Test release candidate.
- Embedded browser-based interface.
- HTTP/TCP download and upload throughput tests.
- HTTP round-trip latency and jitter estimates.
- Host-side persistent JSONL test history and local admin dashboard.
- Optional client JSON and CSV report export.
- Windows BAT launcher with host-port prompt.
- PowerShell online update check, SHA-256 verification, versioned installation, and offline fallback.
- Public release validation remains pending actual two-PC Windows testing.
