# Changelog

## 1.0.0 — Initial public release

- Self-hosted Windows host with browser-only clients.
- HTTP/TCP download and upload throughput tests.
- HTTP round-trip latency and jitter estimates.
- Live throughput graph.
- Host-side JSONL test history and loopback-only admin dashboard.
- Optional client JSON and CSV report downloads.
- Windows BAT launcher with configurable host port.
- GitHub latest-release update check with SHA-256 verification.
- Offline startup from bundled executable or previously installed version.
- Original author attribution: Ajay Raikvar.
